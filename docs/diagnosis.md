# 诊断：为什么「重点不突出」

> 诊断对象：一个 AI 知识类抖音账号的主页封面墙（18 张，3 行 × 6 列）。
> 统一深紫黑底 + 荧光品红，人物半身出镜，左上角栏目、右上角分类、左下点赞、右下作者。

先给结论：**配色是这套封面唯一真正立住的东西，问题在于「什么都舍不得删」。**

---

## 0. 我的观察方法

三个动作，任何账号都能自己复刻：

1. **把整面墙缩到一屏能看完**——不缩放的话你会被单张的细节骗到，看不见「墙纸效应」。
2. **数信息块**——把每个独立的信息单元圈出来（文字块、图形块、数字、图标）。
3. **再缩到 150px 宽**——那就是它在信息流里的真实大小。

做完这三步，问题会自己浮出来。

---

## 1. 六个病灶

### ① 高亮用到泛滥，等于没有高亮

- **现象**：每张 2–4 个品红色块，面积覆盖标题的 60% 以上。
- **证据**：「AI 控制 AI」「装 agent 前先装这 4 个」几乎整句都在色块里；「拉开差距的 · 3 个要素」是两块全宽色条。
- **为什么错**：人眼靠「色块面积差」判断主次，不靠「有没有色块」。当 60% 的字都在高亮，
  高亮就从「强调」退化成「底纹」，成了花纹。
- **怎么改**：一张封面只允许一个高亮单位（一个词，或一个数字，或一根线）。

### ② 信息块严重超载

- **现象**：单张最多数出 12 个信息块、8 级字号。
- **证据**：「装完 agent 接上 GitHub」那期 = 左上栏目药丸 + 右上分类药丸 + 顶部小字 +
  主标白字 + 主标色块 + 副标 + 01/02/03 三张卡片 + 左中浮窗 + 点赞数 + 底部红条 + 水印。
- **为什么错**：信息层级超过 3 层，第 4 层开始就没人看了；留下的只有认知负担。
  更致命的是，01–04 那几张卡缩到信息流里只有 6px 高——**是噪点，不是信息**。
- **怎么改**：删到 3 层。想讲清单？放进视频的前 3 秒，别放封面。

### ③ 字号阶梯断档

- **现象**：主标和副标只差 1.4–1.6 倍，还同色、同字重。
- **为什么错**：视线在封面上只有 0.5 秒。字号差不够，眼睛找不到落点，于是「哪句都想看」→
  「哪句都没看」。
- **怎么改**：主副标至少差 2.5 倍（推荐 1 : 0.3），字重只用两种。

### ④ 人脸和字抢同一块地

- **现象**：人像占画面 40–50%，文字压到肩膀上；有期的浮窗直接贴在人脸边。
- **为什么错**：人的注意力天然先落到脸，但脸和主标的亮度、饱和度一样——等于两个主角在打架。
  被挡住的脸还会产生「别扭感」，虽然观众说不出原因。
- **怎么改**：分出层级——脸压到右下 40%，字永远在脸上方，两者不重叠。

### ⑤ 四角全是杂物

- **现象**：左上栏目、右上分类、左下点赞数、右下作者水印，四个角全占满。
- **为什么错**：平台在信息流里本来就会显示标题和作者，等于同一信息打了两遍；
  而四角恰恰是留白最该呼吸的地方。
- **怎么改**：四角只留一个（建议做成期号细条），其余全删。

### ⑥ 版式一模一样 → 墙纸效应

- **现象**：十几期同一个模子，连色块位置都一致。
- **为什么错**：刷到第 3 张，大脑就归类成「重复内容」并跳过——**识别度反而变成了「没必要看」**。
- **怎么改**：要的不是「每张都不同」，而是「有节奏的同一套系统」：
  2–3 个模板轮换 + 密度呼吸（有的满、有的空）。

## 2. 再往下一层：选题同质化

十几期里有 5 期在讲「AI 团队 / AI 员工 / 招一支 AI 团队 / 一群 AI 员工」。
选题一样，封面只能靠换词区分，越换越挤。

**封面改不动的时候，往往该改的是选题。**

---

## 3. 一个值得记住的对照

把点赞数和「标题具体度」摆在一起看：

| 点赞 | 标题 | 标题特征 |
|---:|---|---|
| 1.8 万 | 我的 AI 员工吵起来了，还有 1 个在劝架 | 具体、有画面、有冲突 |
| 1.3 万 | 装 agent 前，先装这 4 个 | 具体、有数字 |
| 4,694 | AI 控制 AI，一个 Bot 指挥多个 Bot 干活 | 具体但有理解成本 |
| 999 | 装完 agent，接上 GitHub | 专业，但人群窄 |
| 177 | 拉开差距的 3 个要素 | 抽象价值主张 |
| 129 | 动效 PPT 保姆级教程 | 常规教程语气 |

读法：**排版只能保证「看得清」，保证不了「想点」。** 第一层永远是那句话说对了没有。

注意：1.3 万那期恰恰是排版最挤的一张——说明好选题能扛住差排版，
但差选题扛不住好排版。这两件事要分开做。

## 4. 关于配色（单独说）

用户判断「配色可以」，这个判断是对的，但**用量错了**。

- 深紫黑底 + 荧光品红 `#FF2E8B` 作识别色，方向没问题，刷到第三张就能认出是谁。
- 问题在占比：色块 + 右上标签 + 描边字 + 人物补光，全是同一个高饱和粉。
  粉色实际占了画面 30–40%（体感），画面里**没有能停下来休息的地方**。
- 合理的预算是 **70% 暗部 / 20% 中性白 / 10% 一个强调色**。
  他现在是 60 / 10 / 30。

**结论：问题不在选色，在分配。**
